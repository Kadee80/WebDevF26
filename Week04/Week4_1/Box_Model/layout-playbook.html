Same layout, three engines

One nav bar, one photo grid — each built three ways. display: inline-block is the technique for today's class; flexbox and grid are the quick preview at the end. Every demo below is real, live CSS, not a screenshot.

Layout 1 — Nav Bar

A one-row list of links. This is the classic real-world case for getting block-level items to sit side by side.

<!-- same markup for every version below -->
<ul>
  <li>Home</li>
  <li>Projects</li>
  <li>About</li>
  <li>Contact</li>
</ul>

inline-block

⚠ whitespace gap
  • Home
  • Projects
  • About
  • Contact
/* only li changes */
li { display: inline-block; }

The space between pills is real HTML whitespace being rendered like a space between words — not a style. Exaggerated here so it reads at demo size; in real code it's a few px.

flexbox

✓ gap works
  • Home
  • Projects
  • About
  • Contact
/* one change, on the parent */
ul { display: flex; gap: 6px; }

The whitespace gap is simply gone — flex items aren't in an inline formatting context, so source whitespace between them doesn't render. gap does the spacing instead.

grid

✓ gap works
  • Home
  • Projects
  • About
  • Contact
/* also one change on the parent */
ul {
  display: grid;
  grid-auto-flow: column;
  gap: 6px;
}

Works, and no whitespace gap here either — but grid is built for two dimensions. For a single row, flexbox is the more natural tool (that's why the preview in class pairs nav → flexbox).

Layout 2 — Photo Grid

Four cards, four columns. This time we care about the size of each box, not just whether it's inline.

<!-- same markup for every version below -->
<div class="gallery">
  <div class="tile"></div>
  <div class="tile"></div>
  <div class="tile"></div>
  <div class="tile"></div>
</div>

inline-block

⚠ hand-done math
1
2
3
4
/* width % worked out by hand,
   vertical-align keeps tops even */
.tile {
  display: inline-block;
  vertical-align: top;
  width: 23%;
}

Spacing here is the same source-whitespace effect as the nav bar — fine for a demo, fragile in real code. No gap property exists for plain inline-block.

flexbox

✓ gap works
1
2
3
4
.gallery { display: flex; gap: 3%; }
.tile { flex: 1 1 21%; }

Rows equalize height automatically (align-items defaults to stretch) — no vertical-align fix needed.

grid

✓ no math
1
2
3
4
.gallery {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 3%;
}

Compare repeat(4, 1fr) to working out 84% / 4 by hand. This is grid's sweet spot: a real two-dimensional grid of equal-sized boxes.
