# Week 12: objects, and proposal presentations

## Tuesday 17 November: no class

Tuesday's class is cancelled. In its place there is a self-guided lesson, and
it is the most important thing left in this course:

- [Self-guided lesson: JavaScript objects](JS_Objects/README.md)

Budget about two hours. Read it in order and do the Try It boxes as you reach
them. **Due before class on Thursday**, and Thursday assumes you have done it.

Everything you have written so far has used loose variables, one name for one
value. Objects are how you keep related values together, and they are the shape
nearly all real data arrives in. The lesson starts by making you count the ten
loose variables in your own show page, which is the best argument for them I
have.
