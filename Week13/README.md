# Week 13: JSON and APIs

Only one class this week. **Thursday 26 November is Thanksgiving.**

## Class notes

- **Tuesday:** [JSON, and your first API calls](JSON_APIs/README.md). Data
  that arrives from somewhere else while the page is already open, and the
  three things that can happen when you ask for it.

Start from `JSON_APIs/StarterFiles/`. The HTML and the CSS are done. Open the
console and keep it open.

## What this is building on

Everything, more or less:

- **Week 9:** arrays, `.length`, the `for` loop, template literals.
- **Week 10:** `querySelector`, `textContent`, `innerHTML`, event listeners.
- **Week 11:** `classList`, reading an input's value.
- **Week 12:** objects, nested objects, arrays of objects, and JSON.

What comes back from an API **is** an array of objects. You already know how to
read one. The new part is the waiting.

## The sentence this week is about

**The data is not there when the page loads. It arrives.**
