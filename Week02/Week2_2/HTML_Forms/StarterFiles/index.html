Class Cookbook

Last class we marked up a recipe as a web page. Today we build the form someone would fill out to send us one. Every input type below is here because this particular form needs it. For more information see W3 Schools Tutorials. Whenever you need to make an anchor tag but you don't have the final link/url yet... use the # for your href!

1. Who is cooking?

Text, email and password inputs. The box and title you see around this group are created by the fieldset and legend tags.

2. The recipe

Text, number and range inputs, and a dropdown.

3. How hard is it?

Radio buttons allow the user to select ONLY one value at a time. Radio buttons in the same "group" share one name but have different pre-defined values. A recipe has exactly one difficulty, so: radio.



4. Dietary tags

Check boxes allow the user to select more than one value at once. Checkboxes in the same "group" share one name but have different pre-defined values. A dish can be vegetarian AND gluten free, so: checkbox.




5. The actual food

Textarea tags are great for longer text answers, and sentences and paragraphs. Note that textarea has a closing tag and no value attribute — whatever you put between the tags is the starting text.




6. Extras

A few more input types you will meet again later in the semester.




Finally, we use a button to submit our form!
