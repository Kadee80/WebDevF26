Checkbox Groups

Check boxes allow the user to select more than one value at once. Grouped checkboxes (aka for the same answer) all share the same name attribute. The value attribute is what gets sent to the server if that checkbox is checked.


Radio Groups

Radio groups allow the user to select only one value at a time. Grouped radio buttons (aka for the same answer) all share the same name attribute. The value attribute is what gets sent to the server if that radio button is selected.
