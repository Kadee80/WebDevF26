The header is position: sticky, so it stays at the top of the window while the page moves underneath it. The menus need z-index for the same reason: they have to sit above whatever is passing beneath them.

What is worth stealing here

  • position: relative on the li, position: absolute on the submenu.
  • Opening with opacity and visibility instead of display, so it can fade.
  • :focus-within next to :hover, so a keyboard opens the menu too.
  • A short delay before the menu closes, so a slightly wobbly mouse does not lose it.
