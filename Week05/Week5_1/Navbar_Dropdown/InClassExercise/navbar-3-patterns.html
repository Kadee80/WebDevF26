Four dropdowns, one technique

Every menu on this page is a <ul> inside an <li>, hidden until its parent is hovered, and pulled out of the flow with position: absolute. The only thing that changes between them is what the menu is measured against and which edges are pinned.

Hover the highlighted item in each bar.

1 The basic dropdown

Menu hangs below its parent, left edges lined up. This is the one in the walkthrough, and the one you will use 90% of the time.

2 Right-aligned, for the last item

A menu on the last item in the bar runs off the side of the window. Pin the right edges instead of the left and it opens inward. Nothing else changes.

3 The mega menu

Same idea, different parent. The panel is measured against the bar rather than the item, so it can stretch the full width and hold columns. Move position: relative up one level and pin both sides.

4 The third-level flyout

A menu inside a menu. There is no room below, so it goes out to the side: left: 100% puts its left edge on its parent's right edge, and top: 0 lines the tops up. Every level needs its own positioned parent.

Two levels is the practical limit. Three means somebody has to hold a mouse steady across two moving targets, and on a phone there is no hover at all — which is the real argument for a mega menu instead.

What is shared by all four

/* open with opacity + visibility, never display: none, so it can fade */
.submenu, .mega { opacity: 0; visibility: hidden; }

/* :focus-within opens the menu for the keyboard, exactly like :hover */
.has-menu:hover > .submenu,
.has-menu:focus-within > .submenu { opacity: 1; visibility: visible; }

The transition on the resting state carries a small delay, so the menu waits a beat before closing. Open one and drag the mouse off sideways to feel it.
