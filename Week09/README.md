# Week 09 — Your first JavaScript

Midterms are behind you. From here the class is about making pages *do* things
rather than just look like things.

Both classes build one page: a ticket page for a show, where **nothing is typed
in by hand**. Every price, message and line of the order is worked out by the
code.

## Class notes

- **Tuesday:** [JavaScript Variables With a Purpose](Week9_1/JS_Variables_Show_Page/README.md) — numbers, strings and booleans, and a page that works out its own prices
- **Thursday:** [Math, `Math.random()` & Random Content](Week9_2/Math_Random_Content/README.md) — arrays, the Math object and a `for` loop, so the page invents a different show every time it loads

Thursday carries straight on from Tuesday's file, so **keep it**. If yours ends
up in a strange state, Thursday's `StarterFiles/` is exactly where Tuesday
finished.

## What you need

Nothing to install. A browser, your editor, and **devtools open** — this is the
first week where the console is part of the work rather than somewhere errors
go to be ignored.

| | |
|---|---|
| Open devtools | **Cmd + Option + J** (Mac) · **F12** (Windows) |
| The tab you want | **Console** |
