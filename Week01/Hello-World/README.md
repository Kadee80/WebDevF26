## In class exercise

- In your new repo, make a folder called `Hello_World`
- Inside it, create a file called `README.md`
- Write something in it. Keep it professional — this is about to be public on
  GitHub.
- Save it.

Then follow the loop in
[SETUP.md §6](../../SETUP.md#6-handing-in-work): `git status`, `git add .`,
`git commit -m "..."`, and we'll push next class once everyone has a token.

## Markdown

You will document everything in this class with markdown files. It is the same
formatting language this page is written in.

- [Markdown cheat sheet](https://www.markdownguide.org/cheat-sheet/)

**[InClassExercise/recipe.md](InClassExercise/recipe.md) is a worked example** —
a real recipe written in markdown, using headings, both kinds of list, a link,
and an image. That is exactly the shape your `recipe.md` homework should take.
Read it on GitHub to see it rendered, then open the raw file to see the markdown
that produced it. Next week we mark this same recipe up in HTML.
